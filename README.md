## 本分支已包含的最新改动

- 曲线分析页改为至少 6 个独立子图，每个子图可单独选择显示曲线，避免所有曲线挤在一个图内。
- 曲线通道侧栏加入可收起能力，收起后主图区域释放更多空间。
- 设备工作区电机摘要改为两行结构：第一行左侧电机 ID、右侧红/绿状态灯，第二行显示当前值。
- 日志筛选支持 `warning`、`error`、`info`、`bug` 四类，并为不同级别配置不同颜色。
- 卡片拖拽/缩放弱化显式按钮，保留长按拖动和边界缩放的交互方向。
- 增加布局回归和视觉烟雾测试守卫，防止页面重新出现大面积空白、侧栏不可收起、子图区域未填满等问题。

## 下一步开发规划

1. 完成视觉验收闭环：逐页检查桌面宽屏、窄屏、浅色主题、深色主题截图，重点确认无不允许的垂直滚动、无内容裁切、无大面积无意义空白。
2. 继续打磨设备工作区：补齐真实设备数据下的电机、传感器、命令队列、告警区域显示密度与优先级。
3. 完成曲线分析页交互细节：保存每个子图的曲线选择、缩放状态、暂停状态和导出配置。
4. 完善卡片自由布局：长按空白区域拖动、拖拽边界缩放、布局自动保存、布局恢复默认。
5. 统一主题与状态色：检查按钮、禁用态、表格、标签、日志级别、窗口控制区在浅色/深色主题下的对比度。
6. 补齐稳定性验证：继续排查启动卡顿、页面切换阻塞、Three.js 渲染资源释放和 Tauri 命令异常兜底。
7. 打包桌面 exe 验收：确认所有 Tauri 命令在桌面运行时可用，避免浏览器环境误报。

## 验收重点

- 页面主体不出现不必要的全局垂直滚动条。
- 重要数据显示完整，不因卡片高度或布局压缩被裁切。
- 曲线页至少 6 个子图可用，每个子图可独立配置曲线。
- 日志四类级别颜色可明显区分。
- 卡片拖拽和缩放不依赖突兀的“调整布局”按钮。
- 浅色/深色主题下按钮背景和文字颜色都有足够区分度。
